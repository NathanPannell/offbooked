# Offbooked

Remote line recording and run-through playback for theatre casts.

A director uploads a script and shares one link per actor. Each actor opens their link on a phone, records their lines with cue context, and is done in minutes. The server stitches every take into one normalized run-through with a synced, lyrics-style script view, including a "my part" mode that leaves gaps for you to speak your lines.
